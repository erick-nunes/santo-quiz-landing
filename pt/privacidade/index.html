Política de Privacidade

Aplicativo Santo Quiz

Português · English · Español

Última atualização: 20 de novembro de 2026

1. Introdução

Bem-vindo ao Santo Quiz. Esta Política de Privacidade explica como coletamos, usamos e protegemos suas informações ao utilizar nosso aplicativo de quiz católico.

2. Informações que coletamos

2.1 Informações que NÃO coletamos

  • Dados pessoais identificáveis (nome, e-mail, telefone).
  • Localização geográfica.
  • Informações de contatos.
  • Fotos ou arquivos pessoais.
  • Dados de microfone ou câmera.

2.2 Informações coletadas automaticamente

  • Pontuações e progresso no quiz (armazenados localmente no dispositivo).
  • Preferências de jogo (idioma e nível de dificuldade selecionados).
  • Dados técnicos básicos para funcionamento do app (tipo de dispositivo, versão do sistema operacional).
  • Token anônimo de notificações push (sem identificação pessoal), quando o usuário aceita receber notificações.

3. Como usamos as informações

As informações coletadas são usadas exclusivamente para:

  • Permitir o funcionamento adequado do aplicativo.
  • Salvar seu progresso e pontuações localmente.
  • Melhorar a experiência do usuário.
  • Fornecer as perguntas do quiz.
  • Enviar notificações push sobre novos quizzes (apenas se você optar).

4. Compartilhamento de dados

Não compartilhamos, vendemos ou transferimos suas informações pessoais para terceiros.

O aplicativo se conecta apenas ao nosso servidor para buscar as perguntas do quiz.

5. Armazenamento de dados

  • Todos os dados de progresso são armazenados localmente em seu dispositivo.
  • Não mantemos bases de dados com informações pessoais dos usuários.
  • Você pode limpar todos os dados do aplicativo através das configurações do seu dispositivo.

6. Segurança

  • Conexões seguras (HTTPS) com nosso servidor.
  • Não coletamos dados sensíveis.

7. Dados de menores

O Santo Quiz é apropriado para todas as idades. Não coletamos conscientemente informações pessoais de crianças.

8. Seus direitos

  • Usar o aplicativo sem fornecer dados pessoais.
  • Deletar todos os dados locais limpando o cache do aplicativo.
  • Desinstalar o aplicativo a qualquer momento.
  • Desativar notificações push nas configurações do sistema.

9. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos sobre mudanças significativas através de uma atualização do aplicativo.

10. Permissões do aplicativo

  • Internet: para buscar perguntas do quiz.
  • Estado da rede: para verificar conectividade.
  • Notificações: para avisar sobre novos quizzes (opcional).
  • Áudio: para reproduzir sons de feedback do jogo.
  • Vibração: para feedback tátil (opcional).

12. Conformidade legal

Esta política está em conformidade com:

  • Lei Geral de Proteção de Dados (LGPD) — Brasil.
  • General Data Protection Regulation (GDPR) — União Europeia.
  • Children's Online Privacy Protection Act (COPPA) — Estados Unidos.

Ao usar o Santo Quiz, você concorda com esta Política de Privacidade.
